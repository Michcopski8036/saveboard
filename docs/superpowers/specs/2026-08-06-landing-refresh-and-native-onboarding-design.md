# 랜딩 리프레시 + 네이티브 온보딩 — 설계

**Status:** 구현 완료 2026-08-06 — **단, B2(뷰 섹션)는 실행 중 폐기됐다.** 아래 B2 항목 참조.

## 왜 하는가

두 가지 문제가 같은 코드 한 줄에서 나온다. `App.tsx`의 로그아웃 분기는 플랫폼을
구분하지 않는다.

```
if (!user) {
  if (showAuth) return <Auth />;
  return <LandingPage onGetStarted={() => setShowAuth(true)} />;
}
```

**문제 1 — 네이티브에서 랜딩이 뜬다.** 앱을 이미 설치한 사람이 앱을 열면 "앱스토어에서
다운로드" 배지가 박힌 마케팅 페이지를 본다. 창업 스토리와 푸터까지 지나야 로그인에
닿는다. 부수적으로 **iOS 앱 안에서 Google Play 배지가 렌더링된다** — 외부 스토어로
유도하는 모양새라 심사에서 지적받을 수 있다.

**문제 2 — 랜딩이 제품보다 낡았다.** 코드에 있는데 랜딩에 없는 것:

| 기능 | 코드 위치 | 랜딩 |
|---|---|---|
| 뷰 3종 (masonry/gallery/kanban) — 데스크톱 전용 | `App.tsx:985-989` | 없음 |
| 파일 업로드 (무료 5MB·50MB / Pro 20MB·2GB / Team 50MB·10GB) | `App.tsx:663-664` | 없음 |
| 팀 보드 멤버 초대 + **초대된 멤버 무료 참여** | `BoardShareModal.tsx` InviteTab | 없음 |
| 6개 언어 (en/ko/ja/zh/es/fr) | `LanguageContext.tsx:17` | 없음 |

동시에 솔루션 그리드 6칸 중 2칸이 다른 섹션과 중복이다.

## A. 네이티브 온보딩

**새 파일** `src/app/components/Onboarding.tsx`

### 분기

```
if (!user) {
  네이티브 && 온보딩 미열람 → <Onboarding onDone={...} />
  네이티브 && 열람함        → <Auth />
  웹                        → 기존 그대로 (showAuth ? <Auth/> : <LandingPage/>)
}
```

- 조건: `Capacitor.isNativePlatform()` && `localStorage.sb_onboarded !== '1'`
- 건너뛰기/완료 시 플래그 저장 → 이후 로그아웃해도 바로 로그인 화면
- **웹 코드 경로는 한 줄도 안 바뀐다.** SEO 프리렌더·사이트맵·랜딩 그대로.
- 딥링크 안전: `/share/:token`, `/team/:token`, `/reset-password`, `/guides/*`는
  `main.tsx`에서 `<App/>` 밖 별도 라우트라 온보딩이 가로채지 않는다.

### 슬라이드 3장

기존 `public/app/*.jpg` 3장 재사용 — 새 자산 불필요.

| # | 이미지 | 문구(ko) |
|---|---|---|
| 1 | `app-saves.jpg` | 링크를 붙여넣기만 하세요 / 제목·이미지·설명은 자동으로 |
| 2 | `app-boards.jpg` | 활동별로 보드를 나눠서 / 농구, 여행, 레시피 따로따로 |
| 3 | `app-boards-move.jpg` | 필요할 때 몇 초 만에 / 검색하고, 옮기고, 공유하고 |

### 동작

- 가로 스와이프는 CSS `scroll-snap` — 라이브러리 추가 없음
- 하단 도트 인디케이터 + `다음`/`시작하기` + 우상단 `건너뛰기`
- 문구는 `LandingPage`/`Auth`와 같은 패턴의 컴포넌트 로컬 `COPY` 객체(en/ko)
- 상·하단 `env(safe-area-inset-*)` 적용 (iOS `contentInset: "never"` 전제)

### 함께 고치는 것

`LandingPage`의 스토어 배지에 플랫폼 가드 — 네이티브에서는 양쪽 배지 모두 숨김.
온보딩이 들어가면 네이티브는 랜딩을 안 보게 되지만, 안전장치로 남긴다.

AI 검색, 창업 이야기, 최종 CTA. SEO·카피 톤 자산이라 건드리지 않는다.

### B2. ~~새 섹션 — 뷰 3종~~ — **폐기 (2026-08-06)**

**랜딩에 넣지 않기로 했다.** 캡쳐하려고 실제 앱을 열어보고 나서 내린 결정이며,
이유는 기능이 홍보할 상태가 아니기 때문이다:

1. **모바일에서 토글이 아예 안 보인다** (`App.tsx:1112` `hidden sm:flex`).
   SaveBoard 방문자·사용자 다수가 폰이다. 랜딩에서 보고 폰에서 찾으면 없다.
2. **보드를 열어야만** 나오고(홈 대시보드에서는 숨김), 라벨 없는 아이콘 3개라
   지금도 사실상 아무도 못 찾는다.
3. **갤러리 뷰는 대부분 빈 화면이다.** URL을 `<iframe>`으로 임베드하는 구조라
   프레임 차단(X-Frame-Options / CSP frame-ancestors)하는 사이트 — 즉 대부분의
   사이트 — 는 아무것도 렌더되지 않는다. 봇 계정 가이드 보드의 식당·앱 링크는
   전부 차단됐다.
4. **칸반은 깨진 썸네일투성이였다.** 이건 실제 버그였고 **고쳤다**(아래 참조).

즉 "쓸 수 있는 기능인데 안 알려진" 게 아니라 **"대부분의 사용자가 도달할 수
없는 기능"** 이었다. 랜딩에서 광고하면 클릭한 사람이 폰에서 못 찾고 끝난다.

**여기서 나온 실제 버그 수정 (커밋 `5052504e`):** `KanbanView.tsx`가 이미지 없는
링크를 `<img src="">`로 렌더해 브라우저 기본 깨진-이미지 아이콘을 그렸다. 카드
뷰(`LinkCard`)는 원래부터 플레이스홀더로 폴백했는데 칸반만 안 했다. 원격 이미지가
404일 때의 `onError` 폴백도 같이 넣었다.

**남은 별건 (아직 안 함):** 뷰 기능 자체를 사용자가 도달 가능하게 만들기 —
모바일 토글 노출, 라벨/툴팁, 갤러리를 임베드 가능한 링크에서만 의미 있게 만들기.
이게 되면 그때 랜딩에 넣을 만하다.

**두 번째 제약:** 그 토글은 `hidden sm:flex`(`App.tsx:1112`)라 **모바일에서는 아예

카피가 그렇게 말해야 한다.

- 탭 3개(카드 / 갤러리 / 칸반) → 클릭 시 이미지 스왑

- 탭 이름·아이콘은 `App.tsx`의 `viewModes`와 일치시킬 것

  폰에서 찾다가 못 찾는다.

**범위 밖:** `grid`/`list`를 토글에 노출시키거나 모바일에서 토글을 보이게 하는 것.
별건으로 남긴다.

## 스크린샷 캡쳐

**계정: 가이드 봇 계정** (`~/guides-bot-credentials.txt`, mode 600). 이미
큐레이션된 보드가 있어 새 계정을 만들 필요가 없다.

**주의 — 보드 선별:** 봇 계정의 5개 보드 중 랜딩 페르소나(학부모·코치·모임 리더)에
맞는 것은 농구 앱 / 멜버른 라멘 / 퍼스 한국 BBQ 셋이다. **과다월경 자료 보드는
PeriodVol 마케팅 자산**이라 SaveBoard 랜딩의 사이드바 컷에 찍히면 톤이 어긋난다.
캡쳐 전에 페르소나에 맞는 보드(농구팀 일정 🏀 / 가족 여행 ✈️ / 레시피 🍳)를
채우고 그쪽 위주로 찍는다.

**폐기 — B2와 함께 취소됐다.** 새 스크린샷은 하나도 커밋되지 않았고 `public/app/`은
기존 폰 컷 3장 그대로다.

캡쳐를 시도하면서 확인된 것들(다음에 이 작업을 다시 할 때 유용):
- 봇 계정 보드 5개는 전부 공개된 가이드 콘텐츠라 개인정보 걱정이 없다.
- 뷰포트 1205px에서는 사이드바가 아이콘만 표시돼 보드 이름이 안 찍힌다 —
  '과다월경 자료' 보드 노출 문제가 자연히 해결된다. (xl=1280 이상이면 이름이 나온다)
- 앱 언어는 캡쳐 전 English로 맞춘다. 기존 `public/app/*.jpg`가 영어다.
- **봇 계정 Unsorted에 `Test Restaurant One/Two`(example.com) 테스트 데이터 2건이
  남아 있다.** 지우지 않았다 — 파괴적 작업이라 별도 확인이 필요하다.

`public/app/`에 저장, 기존 3장과 같은 jpg 포맷·비율.
**`store/screenshots/play/*.png`는 쓰지 않는다** — 홍보 문구가 이미지에 박혀 있어
본문에서 광고처럼 보인다.

## 검증

자동 테스트가 없는 리포다. 다음으로 확인한다.

1. `npm run typecheck` 0 에러 (빌드 게이트)
2. `npm run build` — 프리렌더/사이트맵 정상 생성
3. 웹: 로그아웃 상태에서 랜딩 → 새 섹션 렌더링, 뷰 탭 스왑 동작, 푸터 언어 줄
4. 네이티브: `npx cap sync ios` 후 시뮬레이터에서
   - 첫 실행 → 온보딩 3장 → 로그인
   - 건너뛰기 → 로그인, 앱 재시작 시 온보딩 안 뜸
   - 로그아웃 → 온보딩 없이 바로 로그인
   - 랜딩에 도달할 경로가 없는지, 도달하더라도 스토어 배지가 없는지
5. `/share/<token>` 딥링크가 온보딩에 가로채이지 않는지
