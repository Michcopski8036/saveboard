# 링크 저장 앱 SaveBoard — 북마크를 보드로

브라우저 북마크바를 마지막으로 열어본 게 언제인가요. 저장은 계속 하는데 다시 열지 않는 이유는 대개 같아요. **저장된 모습이 파란 글씨 한 줄**이라, 목록을 봐도 그게 뭐였는지 기억나지 않기 때문이에요.

SaveBoard는 링크를 **카드**로 저장해요. 제목, 설명, 미리보기 이미지가 같이 붙어서 목록을 훑기만 해도 알아봐요. 그 카드를 **보드**로 묶고, 보드는 링크 하나로 다른 사람에게 넘길 수 있어요.

---

## 어떤 사람이 쓰나요

- **단톡방에서 링크를 계속 받는 사람** — 학부모방, 동호회방, 팀 채팅방
- **폰에서 저장을 끝내고 싶은 사람** — 인스타그램·유튜브·브라우저의 공유 버튼으로 저장
- **자료를 쌓아두고 다시 찾아야 하는 사람** — 기획, 1인 사업, 공부

## 3단계로 끝나요

1. **저장해요.** 링크를 붙여넣거나, 다른 앱의 공유 버튼에서 SaveBoard를 골라요. iOS와 안드로이드 모두 공유 시트에서 바로 저장돼요.
2. **보드로 묶어요.** '학교', '레시피', '이사 준비'처럼 크게 나눠요. 순서는 끌어서 바꿔요.
3. **필요하면 통째로 건네요.** 보드를 공개 링크로 만들면 **받는 사람은 계정 없이** 브라우저에서 열어봐요.

메모(리치 텍스트), 검색, 정렬, 파일 첨부도 있어요. 화면은 앱 언어를 따라 **한국어**로 나와요.

## 다른 앱과 비교하면

|  | SaveBoard | Raindrop.io |
|---|---|---|
| 주 사용 환경 | 모바일 | 데스크톱 |
| 저장 방식 | 공유 시트 | 브라우저 확장 |
| 기본 보기 | 카드 | 목록 |
| 보드 전체 공유 | 계정 없이 열림 | 컬렉션 공유 |
| 무료 범위 | 저장 30개 | 무제한 |
| 한국어 화면 | 있음 | 없음 |

정리 옵션이 많고 데스크톱에서 수백 개를 다룬다면 Raindrop.io가 더 맞아요. 폰에서 저장하고 단톡방으로 다시 넘기는 흐름이라면 SaveBoard가 맞고요. 2025년에 문을 닫은 포켓에서 옮겨오는 경우는 [포켓 종료 후 쓸 대체 앱](/pocket-alternative-ko)에 따로 정리했어요.

## 요금

- **무료** — 저장 30개, 보드 5개. 카드 등록 없이 시작해요.
- **Pro** — 월 A$5.49 또는 연 A$34.99. 저장 무제한, 보드 15개, 저장공간 2GB.
- **Team** — 월 A$9.49. 함께 쓰는 팀 보드, 보드 50개, 저장공간 10GB.

가격은 호주 달러(AUD) 기준이에요. 호주 밖에서는 은행이 결제 시점 환율로 환전해요.

## 어디서 쓸 수 있나요

웹, iOS, 안드로이드예요. 같은 계정으로 로그인하면 보드가 기기 사이에서 이어져요.

## FAQ

### 무료로 쓸 수 있나요

네. 저장 30개, 보드 5개까지 무료이고 카드 등록이 필요 없어요. 보드 공유도 무료 범위에서 돼요.

### 저장한 링크를 다른 사람에게 보여줄 수 있나요

보드 단위로 공개 링크를 만들 수 있어요. 받는 사람은 계정도, 앱 설치도 없이 브라우저에서 열어요. 링크는 언제든 해제할 수 있어요.

### 인스타그램이나 유튜브 링크도 저장되나요

네. 해당 앱의 공유 버튼에서 SaveBoard를 고르면 카드로 들어가요. 미리보기 이미지는 그 페이지가 제공하는 정보를 그대로 가져와요.

### 브라우저 확장 프로그램이 있나요

없어요. 지금은 웹에서 링크를 붙여넣거나, 모바일 공유 시트로 저장하는 방식이에요.

### 한국어를 지원하나요

네. 앱 화면이 한국어로 나오고, 설정에서 언어를 직접 고를 수도 있어요.
