# Hooks — 2026-07-27

Pass 1 of the Monday content batch. **This week's harvest is thin — 4 usable
hooks, all English, all pulled from Raindrop.io review platforms.** Read the
"What didn't work" section below before assuming the gap is coverage, not
effort — it's a genuine dry well on the two angles that matter most

## Tooling caveat — read this before using anything below

WebFetch (direct page retrieval) returned HTTP 403 for *every* URL attempted
this session, including non-adversarial control cases like a plain Wikipedia
article — this looks like a session-level proxy/tool outage, not individual
sites blocking the crawler. That means every quote below was surfaced via
the WebSearch tool's own synthesis of a page (which sometimes echoes exact
quoted text from a source it found), not by me reading the source page
directly. I could not independently re-verify the exact character-for-character
text against the live page the way I normally would before shipping a quote.
**Before any of these ships in copy, someone should open the source URL and
confirm the wording matches exactly.** I'm labeling confidence per-item below.

  `/raindrop-alternative` landing page

  SaveBoard has (or fixes) multi-level nested folder groups unless someone
  confirms SaveBoard actually supports that structure. Safe to use the
  *customer-service-felt-dismissive* angle; unsafe to use the
  *organization-structure* angle without checking the product first.

## What didn't work (report honestly, not padded)

I ran roughly 25 distinct searches across two full passes — English and
Korean run as genuinely separate queries, not translations of each other —
targeting every angle in the brief:

- **Losing links in group chats** (WhatsApp, KakaoTalk, Messenger, Band,
  school/sports/community chats) — no verbatim first-person quote surfaced
  in either language, despite searches phrased as Reddit posts, Quora
  questions, parenting-forum threads, and coach/team-manager complaints.
  Search results kept returning either (a) news coverage of Korean parent
  group-chat *scandals* (bullying, teacher disputes) — a real but unrelated
  topic — or (b) generic app-listing copy for team-management apps
  (TeamSnap, Band, etc.), not user complaints.
- **Bookmark clutter / "I save things and never find them again"** —
  plenty of *evidence the problem exists* (Notion-alternative vendors sell
  against it, ADHD-declutter books reference it) but nothing I could
  isolate as a real person's own sentence with a checkable source, as
  opposed to another company's marketing copy describing the problem in
  the abstract.
- **Ex-Pocket users** — found the shutdown timeline and alternative-app
  roundups (Instapaper, Raindrop, Readwise Reader, Matter) but no quoted
  user reaction beyond one unattributed paraphrase ("used Pocket
  religiously... came as an unwelcome surprise") that wasn't presented in
  quotation marks by the source, so I'm not treating it as a real quote.
- **mymind and Notion-as-bookmark-tool competitor complaints** — found
  paraphrased *descriptions* of complaints (search functionality "not
  good" on mymind; Notion requires manual tagging) but the underlying
  source pages were 403'd, and the phrasing read like second-hand review
  summaries or a competing vendor's own landing-page copy
  (contextbolt.com, which sells a Notion alternative) rather than an
  authentic user's words. I'm deliberately not quoting these as hooks —
  they'd be laundering someone else's marketing copy as a "real" quote,
  which is the exact trap this job exists to avoid.
- **Korean-language sources overall** — I searched 단톡방, 학부모 단톡방,
  밴드 (Band app), 카톡, and Korean bookmark-app names (포킷/Pokit,
  링크풀) directly in Korean, on Naver blog, Tistory, Clien, Brunch,
  a-ha (Q&A), Daum cafe, and Korean App Store review pages. All either
  404'd on WebFetch or returned no quotable first-person text via
  WebSearch — the tool kept surfacing product-description copy ("링크풀은
  링크를 카테고리별로 정리...") rather than user complaints. I did not
  translate an English hook into Korean to fill the gap, per the brief;
  the honest result is zero Korean hooks this pass.
