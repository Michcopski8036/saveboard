**Verified against the current repo before writing shots:**
- **Save flow, Android:** share sheet → `SendIntent.checkSendIntentReceived()` (`App.tsx`)
  opens the Add modal pre-filled with the URL. Board picker is multi-select chips
  (`categories.map`, `App.tsx` ~1362-1384) — you can drop one link into several boards
  at once before tapping Add.
- **Save flow, iOS:** native Share Extension (`ios/App/ShareExtension/ShareViewController.swift`)
  — shows its own mini preview card with icon/title/host and a "Save to SaveBoard"
  button *inside the share sheet itself*, no need to open the app. Board assignment
  happens back in the app afterward, not in the extension.
- **Search:** live filter on **title, description, and URL** as you type
  (`App.tsx` line ~1531), 8 results shown. Confirmed still true on current main.
- **Reminders (Pro):** card `⋯` menu → **"Remind me"** (amber-badged PRO for free
  users, opens the upgrade page instead) → three presets, exact on-screen strings:
  **"Tomorrow 9am" / "In 3 days" / "Next week"** (`LinkCard.tsx` ~588). Sets an amber
  clock chip on the card. This UI is **English-only** — no Korean strings for it in
  `translations.ts` — so the Reminders script below is EN, and shows English button
  labels even though the demo account can otherwise be in Korean.
- **Board sharing:** `BoardShareModal.tsx`, "Invite people" tab — enter an email,
  tap Send → `sendBoardInviteEmail`; if that fails, falls back to opening the device's
  mail app pre-filled. Also a "copy invite link" option. Fully localized
  (`inviteToEdit`/`inviteByEmail` both have Korean strings) — confirmed real, not
  implying delivery guarantees hooks #5 flagged as unverified for the competitor.
