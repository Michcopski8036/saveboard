# Shortform scripts — 2026-07-27 (Pass 2)

Built from `marketing/hooks/2026-07-27.md`. **5 scripts, not 6.** The hook
pass came back with 4 usable hooks, all English, all Raindrop.io reviews,
all flagged medium/low confidence (WebFetch was down all session, so no
quote below was independently re-verified against its live source page —
see the caveat in the hooks file). Zero Korean hooks — the researcher ran a
real, thorough Korean-language pass and found nothing quotable as a real
person's own sentence about 단톡방/학부모 단톡방/밴드 link loss.

That means:
- **3 English scripts**, each citing a specific hook number, each carrying
  forward the "verify wording before posting" flag from the hooks file.
- **2 Korean scripts**, about the same well-known 단톡방 link-loss problem,
  but with **no sourced quote**. On-screen text is plain observational
  text, not attributed to anyone. I did not translate an English hook into
  Korean or invent a Korean "quote" to hit a round number — that's exactly
  the fabrication the brief tells me to avoid. If a Korean hook surfaces in
  a future pass, these two should be revisited/replaced with hook-grounded
  versions.

Format mix across the batch: 3 demo, 2 relatable — close to the 2:1 target
given only 5 scripts total.

Every screen-demo shot below was checked against the actual save/share and
search code in this repo before being written (`src/app/App.tsx`,
`ios/App/ShareExtension/ShareViewController.swift`) — not assumed. Two
things that shaped the scripts:

- **Android** share-into-SaveBoard opens the **Add modal pre-filled with the
  URL** and waits for the user to pick a board and tap Save — this is a
  filmable, multi-step demo. **iOS** share-extension saves happen in the
  background once you tap "Save to SaveBoard" in the share sheet (no
  in-app confirmation modal) — so the iOS share sheet itself is the whole
  demo; don't script an iOS in-app step that doesn't happen. Both scripts
  below use the **Android** flow because it's the one with an on-screen
  board-picker moment to shoot.
- **No nested/grouped collections.** `src/app/lib/boards.ts` confirms
  boards are a flat list (`name`, `sort_order`, no parent/group field). Per
  the hook file's product-implication flag on Hook 1, none of these
  scripts imply SaveBoard has folder-groups or nested collections — Hook 1
  is used only for its safe angle (feeling dismissed by support), not the
  underlying nested-collections bug.
