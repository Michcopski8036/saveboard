# Shortform batch — 2026-07-19

Built from `marketing/hooks/2026-07-19.md`. 6 scripts: 4 screen-demo (English) / 2 relatable-text (1 English, 1 Korean).

**Note on the Korean/English split.** The hooks file is explicit that Korean-language material this round is thin: only hook #5 (a Korean parent describing a teacher dumping every school notice into a KakaoTalk 단톡방) is a solid, sourced Korean hook. Hook #6 (a Threads post praising visual previews) is flagged by the researcher as weak-confidence and persona-unclear — not safe to quote as if it were a real, attributable hook. Per the brief, I'm not stretching #6 into a script and not translating an English hook into Korean to make up the difference. So this batch ships **1 Korean script** (relatable, hook #5) instead of the usual ~half split, and **5 English scripts**. All 4 demos are English as a result — that's a sourcing gap, not a taste choice; a Korean demo pair (e.g. the save-flow or shared-board demo, re-shot with 단톡방 framing) is a good candidate for next batch if more Korean material turns up.

**Hooks used:** #4 (NYC parent, WhatsApp — verbatim), #5 (Korean parent, 단톡방 — verbatim fragment, lightly trimmed for caption length, substance/vocabulary unchanged), #3 ("faux productivity" — verbatim phrase), #8 (mymind AI-search gap — paraphrase, feature-gap flag applied). **Hooks not used this round:** #1 (mymind price), #2 (Raindrop "slightly confusing"), #7 (Pocket grief) — all still usable, held back to avoid overloading one batch with comparison angles.

**Feature-gap flags respected:** script 5 does not claim SaveBoard has AI/semantic search — it explicitly says the opposite (no AI search, visual recognition instead). No script implies offline reading, article stripping, or a Pocket-style read-it-later experience. No script implies KakaoTalk/WhatsApp-specific integration — every "share to SaveBoard" shot uses the generic OS share sheet.
