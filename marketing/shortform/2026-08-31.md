## 1. [Screen-demo, EN] "I lose track of what I've already read"

**Built on the hook:** "browser tabs pile up, bookmarks get forgotten, and I lose
track of what I've already read." — Hacker News, [Show HN: A native Hacker News
reader with integrated todo/done tracking](https://news.ycombinator.com/item?id=44033009).
Ordinary-saver persona, not group-chat-specific — matches this hook's actual content
rather than stretching it to fit a scene it wasn't about.

**Founder needs to record:** Screen recording, phone, an existing SaveBoard account
with a realistic number of saved links (dozens, mixed boards — the point is visible
volume). Start on a messy home screen with many browser tabs open, then switch to
SaveBoard, type a partial keyword into search, show the match land.

```
HOOK (0-2s)
Screen recording: a phone with 20+ browser tabs open, thumbnails visible.
Caption: "browser tabs pile up. bookmarks get forgotten."

SHOTS
1. (2-5s) Keep scrolling the tab switcher — visual overload, no way to tell
   what's already been read. Caption: "you lose track of what you've already seen"
2. (5-7s) Cut to SaveBoard: tap the search bar. Caption: "so put it somewhere
   search actually works"
3. (7-12s) Type a partial word from a link's title or page description (not the
   exact saved title) — result appears instantly. Caption: "type roughly what
   you remember"
4. (12-14s) Tap the result, it opens. Caption: "there it is"

CTA (14-16s)
Caption: "Save it once. Actually find it again."
Small logo/wordmark corner.
```

**ON-SCREEN TEXT (paste-ready)**
- browser tabs pile up. bookmarks get forgotten.
- you lose track of what you've already seen
- so put it somewhere search actually works
- type roughly what you remember
- there it is
- Save it once. Actually find it again.
