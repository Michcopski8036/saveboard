## Why it's worth checking, if it is alive

MyHealthApps.net (built by the nonprofit PatientView, originally "European Directory of Health
Apps") is populated by patient and disability-group recommendation rather than vendor
self-listing — a different kind of credibility than a generic SaaS directory, and it costs
nothing. That fits PeriodVol's actual audience (people with heavy menstrual bleeding, some with
bleeding disorders) better than AlternativeTo or SaaSHub do. It is a **directory entry, not a
listicle pitch** — the copy below doesn't depend on quoting any specific article, so the
network-access limitation this run doesn't compromise it the way a personalized cold pitch
would.

## Hard rules carried over from PeriodVol's own file (do not drop when pasting)

- **No medical claims.** PeriodVol estimates; it never diagnoses, detects, or screens. This
  matters more here than on a generic SaaS directory — a patient-facing health directory is
  exactly the audience most likely to over-read a claim that isn't there.
- **No fake reviews, no posing as an ordinary patient.** If the survey has a free-text field
  inviting a personal account, write it as the founder's own story (the haematologist /iron
  infusion story already used in every other PeriodVol pitch — see
  `store/founder-story.md` #4 in the PeriodVol repo), not as an anonymous testimonial.
